# 停车场景网页模拟器

一个基于 `React + TypeScript + Vite` 的 2D 停车场景模拟器，用来手动模拟车辆在地下车库中的入库、出库和挪车过程，辅助判断是否会蹭到柱子、墙体或车位边界。

## 功能特点

- 2D 俯视图模拟车辆运动轨迹
- 实时显示车辆轮廓、历史轨迹和扫掠包络
- 显示车辆与关键障碍物之间的最近距离
- 可视化车头、车尾、前轮转角，以及 A / B / C 柱位置
- 支持鼠标拖动车辆位置
- 支持键盘控制车辆前进、倒车和转向
- 支持调整车辆参数、车位尺寸、通道宽度、柱子尺寸
- 支持本地缓存、JSON 导入导出

## 适用场景

- 地下车库倒车入库
- 地下车库出库前的空间判断
- 判断车头、后角、A 柱附近是否接近柱子
- 粗略评估不同车型在同一车位中的挪车难度

说明：
当前版本定位为“工程参考级”几何模拟工具，用于空间判断和刮蹭风险预估，不替代真实车辆官方转弯数据或专业 CAD 工具。

## 本地运行

先安装依赖：

```bash
npm install
```

启动开发环境：

```bash
npm run dev
```

默认开发地址通常为：

```text
http://127.0.0.1:5173/
```

## 构建生产版本

```bash
npm run build
```

构建产物会输出到：

```text
dist/
```

本地预览构建结果：

```bash
npm run preview
```

## 用 Python 运行构建后的网页

先构建：

```bash
npm run build
```

再进入 `dist` 目录启动静态文件服务：

```bash
cd dist
python -m http.server 8000
```

浏览器打开：

```text
http://127.0.0.1:8000
```

如果要让局域网其他设备访问：

```bash
python -m http.server 8000 --bind 0.0.0.0
```

## 交互说明

### 画布操作

- 直接拖动车辆可调整当前车辆位置
- 拖动障碍物可微调柱子位置
- 车辆前方的旋转手柄用于调整车辆朝向

### 键盘控制

- `W` / `↑`：前进一步
- `S` / `↓`：倒车一步
- `A` / `←`：左打方向
- `D` / `→`：右打方向
- `Space`：回正
- `Backspace`：撤销一步
- `R`：重置轨迹

支持长按连续控制。

### 面板功能

- `清除轨迹`：仅清除历史轨迹和扫掠包络，车辆保持当前位置
- `重置轨迹`：回到场景起始车位
- `初始化场景`：清除缓存并恢复默认配置
- `导出 JSON`：导出当前场景、车辆参数和操作历史
- `导入 JSON`：恢复之前导出的配置
