# 开发记录 - 2026-05-17

## 目标

本轮工作围绕“停车场景网页模拟器”进行，重点是把原型逐步打磨成一个可演示、可部署、可继续维护的静态前端项目。

## 本轮完成的主要内容

### 1. 完成停车模拟器首版

实现了一个基于 `React + TypeScript + Vite` 的 2D 停车场景模拟器，支持：

- 车辆前进、倒车、转向模拟
- 车辆轨迹显示
- 车身扫掠包络显示
- 障碍物碰撞判断
- 最近距离提示
- 本地缓存
- JSON 导入导出

### 2. 重构地下车库场景

根据使用反馈，重新设计了地下车库布局，使其更接近真实车库使用场景：

- 上下双排车位
- 中间主通道
- 车位之间保留合理空隙
- 入口柱、间隔柱位置更符合真实车库
- 删除不合理的装饰性障碍线

### 3. 增强车辆可视化

增加了以下辅助识别信息：

- 车头箭头
- 车尾标记
- 前轮转角可视化
- A / B / C 柱标注
- 多条最近距离虚线

### 4. 增强交互体验

新增或优化了以下操作：

- 鼠标拖动车辆
- 鼠标拖动障碍物
- 键盘控制前进、倒车、左右打方向
- 支持长按连续控制
- 撤销一步
- 清除轨迹
- 重置轨迹
- 初始化场景

### 5. 简化编辑面板

对编辑区做了简化：

- 删除“编辑模式”切换按钮
- 起始车位参数改为常驻显示
- 障碍物继续通过点选后在面板里微调

## 本轮解决的关键问题

### 场景真实性问题

修正了不合理的车位方向、柱子位置和墙体布局，使主模板更适合地下车库停车模拟。

### 柱子显示与碰撞不一致问题

将画面中可见的柱子统一纳入距离计算和碰撞判断。

### 车头车尾不易辨认问题

通过增加车头、车尾和前轮方向可视化，让用户更容易判断车辆姿态。

### 柱位标注需求

在画布中增加了左右 A / B / C 柱标注，作为车身空间判断的辅助参考。

### 拖动车辆不稳定问题

修正了：

- 车身命中区域判断
- 高分屏坐标换算
- 拖拽事件稳定性

### 操作历史导致界面抖动问题

通过以下方式减轻抖动：

- 新增“清除轨迹”按钮
- 扩大并居中画布区域
- 将操作历史改为固定高度滚动区
